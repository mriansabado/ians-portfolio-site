# Personal Portfolio Website

This is my personal portfolio website, designed to showcase my skills, projects, and background as a developer. The site is built using **React** and **Tailwind CSS**, and is hosted on **GitHub Pages**. I also designed the background myself using **Procreate** on iPad.

## Features

- **Bio Section**: An introduction to who I am and my professional journey
- **About Page**: A more detailed look at my background, skills, and experience
- **Projects Page**: A showcase of my projects with links to code and demos
- **Community Links**: At the bottom of the page, you'll find links to my work on platforms like GitHub and LinkedIn

## Technologies Used

- **React**: For building the interactive components and single-page layout
- **Tailwind CSS**: For modern, responsive styling
- **GitHub Pages**: For hosting the portfolio

## How to Use

1. Visit the site to learn more about my professional background.
2. Explore my projects and check out the code.
3. Connect with me via the links at the bottom of the page.
